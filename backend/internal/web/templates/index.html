Roteador

Como apontar a casa para este DNS
  1. No DHCP do roteador, coloque {{.ServerIP}} como DNS primário.
  2. Deixe o DNS secundário vazio (ou também {{.ServerIP}}). Com 8.8.8.8 no secundário, parte das consultas escapa.
  3. Se o roteador anuncia DNS IPv6 próprio, desative esse anúncio: aparelhos com IPv6 podem perguntar direto ao roteador.
  4. Nos celulares monitorados, desligue o DNS privado e use o MAC do aparelho na rede de casa.

Se este servidor cair, a casa fica sem DNS. Para voltar ao normal em 1 minuto, deixe o DNS do DHCP do roteador em automático.
